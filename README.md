# Simulateur de boosters

Application web installable (PWA) pour simuler l'ouverture de boosters Pokémon
(TCG Pocket et JCC classique) et suivre sa collection.

- Collection enregistrée sur l'appareil (bouton d'export/import dans l'onglet Collection).
- Fonctionne hors ligne une fois installée.
- Visuels des cartes chargés depuis TCGdex (https://tcgdex.dev) quand ils sont disponibles.

Données : pokemon-tcg-pocket-database (flibustier), TCGdex, PokeAPI.
